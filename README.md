# 💌 Приглашение с ответом в Telegram

Интерактивное приглашение погулять. Любой человек (Асан, Искен и так далее) пишет боту, создаёт **своё** приглашение и получает уведомления **только о своих**. Разработчик управляет местами и смотрит статистику в админке, без правки кода.

```
Асан  → бот → ссылка → Айдана → ответ приходит Асану
Искен → бот → ссылка → Сауле  → ответ приходит Искену
```

---

## Как это работает

1. Отправитель пишет боту `/new`, вводит имя получателя и выбирает «Она» или «Он» (от этого зависят окончания в текстах).
2. Бот присылает ссылку вида `https://сайт/?uid=abc123xyz0`. Имена, пол и места хранятся на сервере, а не в ссылке, поэтому подменить их нельзя.
3. Получатель проходит приглашение: выбирает дату, время и место, при желании отправляет записку.
4. Отправитель получает в Telegram: 👀 «открыл(а) приглашение», 💌 ответ с датой, временем и местом, 💬 записки.
5. На ответ у каждой ссылки одна попытка, записок можно отправить до трёх.

### Команды бота

| Команда | Что делает |
|---|---|
| `/new` | создать приглашение |
| `/my` | список своих приглашений и их статус |
| `/myname Имя` | как подписывать тебя в приглашении (по умолчанию имя из Telegram) |
| `/cancel` | отменить создание |

## Что понадобится

- Аккаунты **GitHub**, **Vercel** и **Upstash** (всё бесплатно)
- Бот от **@BotFather** (`/newbot`), сохрани токен

## Установка

### 1. Redis (Upstash)
Создай Redis Database, во вкладке **REST API** скопируй `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.

### 2. Деплой на Vercel
Загрузи папку проекта в репозиторий GitHub, затем **Vercel → New Project → Framework Preset: Other → Deploy**. Или через CLI: `npm i -g vercel && vercel`.

### 3. Переменные окружения
**Project → Settings → Environment Variables**:

| Имя | Обязательно | Значение |
|---|---|---|
| `BOT_TOKEN` | да | токен от BotFather |
| `UPSTASH_REDIS_REST_URL` | да | URL из Upstash |
| `UPSTASH_REDIS_REST_TOKEN` | да | токен из Upstash |
| `SITE_URL` | да | адрес сайта, например `https://invitation-xxx.vercel.app` |
| `ADMIN_PASSWORD` | да | пароль для админки (длинный и уникальный) |
| `WEBHOOK_SECRET` | рекомендуется | любая случайная строка, защищает вебхук |
| `TZ_OFFSET_HOURS` | нет | сдвиг от UTC для дат в статистике, по умолчанию `6` (Бишкек) |

После добавления сделай **Redeploy**.

### 4. Вебхук бота
Открой в браузере (подставь свои значения):

```
https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=<SITE_URL>/api/webhook&secret_token=<WEBHOOK_SECRET>
```

Ответ должен содержать `"ok": true`. Если секрет не задавал, параметр `secret_token` не нужен.

## Админка

Адрес: `https://твой-сайт/admin`, вход по паролю `ADMIN_PASSWORD`.

- **Статистика**: сколько ссылок создано, открыто, получили ответ и записки; процент перехода между шагами; график за 14 дней; популярные места; последние события.
- **Приглашения**: все ссылки с отправителем, получателем, статусом, выбранными датой и местом; поиск и фильтр; копирование ссылки; удаление.
- **Места**: добавлять, переименовывать, менять эмодзи, описание и адрес, скрывать, менять порядок, удалять. Изменения видны получателям сразу после нажатия «Сохранить места».

После 10 неверных паролей с одного IP вход блокируется на 15 минут.

## Что изменилось в версии 2

- Несколько отправителей, у каждого свои приглашения и уведомления.
- Админка со статистикой, местами и приглашениями.
- Места хранятся в Redis и редактируются без кода.
- Ответ на приглашение отправляется один раз; при сбое сети есть кнопка «Повторить».
- Записка отправляется кнопкой (до трёх штук), а не по таймеру во время набора.
- Уведомление отправителю, когда ссылку открыли; в ответе видно, сколько раз пытались нажать «Нет».
- Кнопка «Нет» после шести нажатий «ломается», но «Да» сама не нажимается.
- Окончания в текстах (ответила/ответил, согласна/согласен) зависят от пола получателя.
- Исправлена дата по умолчанию (раньше считалась по UTC и ошибалась утром).
- Защита: лимиты запросов, проверка полей на сервере, `crypto` вместо `Math.random()`, название места берётся на сервере, ошибки не раскрывают внутренние детали.
- Вёрстка: `100dvh`, прокрутка внутри экрана, зум на телефоне разрешён, видимый фокус, поддержка «уменьшить движение», доступные кнопки.

## Отладка

- Статус вебхука: `https://api.telegram.org/bot<BOT_TOKEN>/getWebhookInfo`
- Логи: Vercel → Deployments → выбранный деплой → Functions
- Бот молчит: проверь, что `setWebhook` вернул `ok: true`, заданы `BOT_TOKEN` и `SITE_URL`, и проект пересобран после добавления переменных
- «Ссылка не найдена»: приглашение удалено или прошло 180 дней
- Админка пишет «ADMIN_PASSWORD не задан»: добавь переменную и сделай Redeploy

## Безопасность

- `BOT_TOKEN` и пароли хранятся только в переменных окружения, не в коде и не в репозитории (`.env` в `.gitignore`)
- `uid` состоит из 10 случайных символов, срок жизни ссылки 180 дней
- Если токен бота когда-либо попадал в репозиторий или скриншот, отзови его в @BotFather (`/revoke`)

## Стоимость

Всё в бесплатных планах: Vercel, Upstash (10 000 команд в день), Telegram Bot API. Для личного использования хватает с большим запасом.
